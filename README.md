# ⚖️ Судебная Система — Умная Платформа для Правосудия

> **Современная, интеллектуальная система управления судопроизводством**, созданная для автоматизации работы судов, цифровизации документооборота и повышения эффективности судебных процессов.

## 🚀 Возможности системы

### 📂 Управление делами
- **Поддержка всех категорий дел**: Уголовные, Гражданские, Административные (КАС РФ) и Дела об административных правонарушениях (КоАП)
- **Единое окно для просмотра карточек дел** с быстрым доступом к движению, сторонам, решениям и ходатайствам
- **Умный поиск** по всем типам дел с фильтрацией по статусу, дате, категории и участникам
- **Автоматическое определение подсудности** с подсказками по этапам судопроизводства

### 📄 Документы и решения
- **Генерация процессуальных документов** из шаблонов (приговоры, решения, постановления)
- **Полнотекстовый поиск** по судебным актам и материалам дел
- **Подписание документов** электронной подписью с сохранением истории
- **Работа с документами сторон**: регистрация, приобщение, возврат, история статусов

### 🔔 Умные уведомления
- **Уведомления о новых документах и ходатайствах** от сторон
- **Контроль процессуальных сроков** с предупреждениями о приближении дедлайнов
- **Кастомные правила** для автоматической отправки уведомлений
- **Интеграция с календарем** заседаний и напоминаниями

### 💬 Встроенный мессенджер
- **Telegram-подобные чаты** для судей, сотрудников и сторон
- **Групповые чаты**, каналы оповещений и служебные каналы
- **Обмен документами** между судами с контролем статуса
- **Поручения и задачи** с отслеживанием выполнения

### 👤 Доступ для граждан (сторон)
- **Вход через Яндекс ID или ВКонтакте** с автоматической привязкой к делам
- **Просмотр дел**, в которых пользователь является стороной
- **Подача ходатайств и досылка документов** онлайн
- **Уведомления о статусе** документов и движении дела

### 🤖 AI-ассистент для судей
- **Автоматический анализ дел** с выявлением нарушений сроков
- **Рекомендации по этапам судопроизводства** на основе данных дела
- **Ссылки на актуальную практику** Пленума ВС РФ и обзоры
- **Помощь в составлении документов** с подстановкой данных из дела

### 📊 Статистика и аналитика
- **Дашборды с ключевыми показателями** по загруженности судей и движению дел
- **Сохранение пользовательских фильтров** для быстрого доступа
- **Экспорт отчетов** в Excel и PDF

### 📦 Управление судами (Реестр судов)
- **Справочник всех судов РФ** с иерархией и контактами
- **Отделы и сотрудники** с распределением ролей
- **Передача дел между судами** (апелляция, кассация, подсудность)
- **Межсудебный обмен документами** с маршрутизацией

### 🎙️ Расшифровка аудиозаписей
- **Автоматическое распознавание речи** судебных заседаний
- **Генерация черновиков протоколов** в формате DOCX
- **Отслеживание прогресса** обработки в реальном времени

## 🏆 Преимущества перед существующими системами

| Критерий | Традиционные ГАС "Правосудие" | Наша система |
|----------|-------------------------------|--------------|
| **Интерфейс** | Устаревший, сложный | Современный, интуитивный |
| **Доступ сторон** | Ограниченный (только через ГАС) | Через Яндекс ID / ВК |
| **AI-помощник** | Отсутствует | Встроенный ассистент для судей |
| **Мессенджер** | Нет | Встроенный Telegram-подобный |
| **Документы** | Только загрузка | Генерация из шаблонов + подписание |
| **Расшифровка аудио** | Отсутствует | Автоматическая (Whisper) |
| **Статистика** | Статическая | Интерактивная, с кешированием |
| **Кастомизация** | Сложная | Гибкие настройки через админку |

## 🛠️ Технический стек

### Бэкенд
- **Python 3.10+** / **Django 4.2** — основной фреймворк
- **Django REST Framework** — API для фронтенда
- **Celery + Redis** — асинхронные задачи (распознавание аудио, уведомления)
- **Django Channels** — WebSockets для мессенджера и уведомлений в реальном времени
- **SQLite** (разработка) / PostgreSQL (продакшн) — основная БД
- **Whisper** — распознавание речи для аудиозаписей
- **LLM (Saiga/Llama)** — AI-ассистент для судей

### Фронтенд
- **React 18** + **React Router v6**
- **CSS Modules** — стилизация компонентов
- **Axios** — HTTP-запросы к API
- **WebSockets** — для мессенджера и live-уведомлений
