🎯 Основная цель
Создание единой цифровой экосистемы для судов, охватывающей все виды судопроизводства. Система обеспечивает полный цикл работы с делом — от регистрации до передачи в архив, с автоматизацией рутинных задач и интеллектуальной поддержкой судей.

🚀 Быстрый старт
Требования
Python 3.10+

Node.js 16+ и npm

Redis (для Celery и Channels)

Git

Установка и запуск
Клонирование репозитория

bash
git clone https://github.com/your-repo/judicial-system.git
cd judicial-system
Настройка бэкенда

bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
source venv/Scripts/activate

# Активация (Linux/Mac)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser
Настройка фронтенда

bash
cd frontend
npm install
Автоматический запуск всех компонентов
bash
# Запуск Redis, Celery, Daphne и React
./start_project.sh
Ручной запуск по компонентам
bash
# 1. Запуск Redis (в отдельном окне)
redis-server

# 2. Запуск Celery (в отдельном окне)
celery -A judicial_document_management worker --pool=solo --loglevel=info

# 3. Запуск Daphne (ASGI сервер)
daphne -b 0.0.0.0 -p 8000 judicial_document_management.asgi:application

# 4. Запуск фронтенда (в отдельном окне)
cd frontend && npm start
